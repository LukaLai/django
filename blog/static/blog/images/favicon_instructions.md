# Instructions pour optimiser le favicon

## Tailles recommandées pour un favicon complet

Pour une compatibilité maximale, vous pouvez créer ces versions de votre logo :

### Tailles principales :
- **16x16px** - favicon classique
- **32x32px** - favicon haute résolution
- **48x48px** - Windows taskbar
- **64x64px** - Windows high-DPI
- **128x128px** - Chrome Web Store
- **180x180px** - Apple Touch Icon
- **192x192px** - Android Chrome
- **512x512px** - Android Chrome high-res

### Formats recommandés :
- **favicon.ico** - Format classique (peut contenir plusieurs tailles)
- **PNG** - Format moderne avec transparence
- **SVG** - Format vectoriel (idéal pour logos simples)

## Outils recommandés pour créer les favicons :

1. **En ligne :**
   - https://favicon.io/
   - https://realfavicongenerator.net/
   - https://www.favicon-generator.org/

2. **Logiciels :**
   - GIMP (gratuit)
   - Photoshop
   - Canva

## Instructions :
1. Uploadez votre logo.png sur un de ces sites
2. Téléchargez le pack de favicons généré
3. Placez tous les fichiers dans le dossier `blog/static/blog/images/`
4. Mettez à jour le template base.html avec les liens appropriés

## Note :
Le favicon actuel utilise directement votre logo.png, ce qui fonctionnera pour la plupart des navigateurs modernes.
